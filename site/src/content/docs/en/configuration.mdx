Copy `.env.example` to `.env` for docker compose, and `.dev.vars.example` to `.dev.vars` for the Worker. In production, set the Worker values as Worker secrets or vars instead. Both example files list every variable the app reads, with a one-line comment.

<p class="note">The <code>casthop_dev_secret_…</code> value in the example files is a documented local default. It is public, so it is not for production. Generate your own keys with <code>lk generate-keys</code>.</p>

## LiveKit

| Name | Purpose | Local default |
|---|---|---|
| `LIVEKIT_API_KEY` | LiveKit API key. | `devkey` |
| `LIVEKIT_API_SECRET` | LiveKit API secret. Keep it in Worker secrets and never send it to the browser. | the documented local default, not for production |
| `LIVEKIT_HTTP_URL` | Where the Worker reaches LiveKit. | `http://127.0.0.1:7880` |
| `PUBLIC_LIVEKIT_URL` | The LiveKit URL browsers connect to. | `ws://127.0.0.1:7880` |

The Worker returns 503 if `devkey` is used with a non-loopback LiveKit URL. `CASTHOP_ALLOW_DEV_KEYS=1` overrides this and exists for tests only.

## Egress

| Name | Purpose | Local default |
|---|---|---|
| `EGRESS_OUTPUT_DIR` | Path inside the egress container. Compose mounts `./data/recordings` here. Not a Worker var. | `/out` |
| `EGRESS_TEMPLATE_URL` | The compositor page Egress opens. | `http://127.0.0.1:5173/egress-template` |

## Destinations

| Name | Purpose | Local default |
|---|---|---|
| `RTMP_YOUTUBE` | Default YouTube destination. | `rtmp://127.0.0.1:1935/live/youtube` |
| `RTMP_LINKEDIN` | Default LinkedIn destination. | `rtmp://127.0.0.1:1935/live/linkedin` |
| `RTMP_X` | Default X destination. | `rtmp://127.0.0.1:1935/live/x` |

These are local MediaMTX stand-ins. New studios copy them only when they point at loopback: any account can create a studio, so a real ingest URL here would hand your stream key to every owner. Owners enter real ingest URLs per studio in the Destinations panel.

## Worker

| Name | Purpose | Local default |
|---|---|---|
| `HOST_KEY_SECRET` | Separate HMAC for Worker-to-Durable-Object host keys. Falls back to `LIVEKIT_API_SECRET` if unset. Set it in production. | unset |
| `PUBLIC_ORIGIN` | Public site URL for magic-link mail, co-host invites and GitHub OAuth. | unset (loopback Host is used) |
| `CASTHOP_TRUST_FORWARDED` | Set to `1` to trust `CF-Connecting-IP` and `X-Forwarded-For` behind a reverse proxy. | unset |
| `CASTHOP_ALLOW_DEV_KEYS` | Allow the published dev keypair with a non-loopback LiveKit. Tests only. | unset |

## Timing overrides

Optional. Unset means the code defaults in `worker/egress.ts`. Tests set some of these to `0` or a few milliseconds.

| Name | Purpose | Default |
|---|---|---|
| `CASTHOP_EMPTY_GRACE_MS` | End live after the studio has been empty this long. | `45000` |
| `CASTHOP_COMPOSITOR_GRACE_MS` | Wait for compositor Chrome to join after StartRoomComposite. | `15000` |
| `CASTHOP_RECOVERY_MS` | Give up restarting a dead compositor; host can Retry. | `30000` |
| `CASTHOP_HEARTBEAT_MS` | Compositor beat is stale after this (the page posts every 1 s). | `3000` |
| `CASTHOP_BACKOFF_MS` | Override RTMP retry backoff. Unset = 1 s, 2 s, 4 s, 8 s, 16 s, 30 s. `0` for tests. | unset |

## YouTube Live chat

Comments from the YouTube broadcast appear in the studio chat panel while the show is live. The host can pin one onto the compositor overlay. Unset credentials hide this; the studio does not error.

| Name | Purpose | Local default |
|---|---|---|
| `YOUTUBE_API_KEY` | YouTube Data API key for public `liveChatMessages.list`. | unset |
| `YOUTUBE_LIVE_CHAT_ID` | Skip lookup and poll this live chat. | unset |
| `YOUTUBE_VIDEO_ID` | Resolve `activeLiveChatId` from a video. | unset |
| `YOUTUBE_OAUTH_CLIENT_ID`, `YOUTUBE_OAUTH_CLIENT_SECRET`, `YOUTUBE_OAUTH_REFRESH_TOKEN` | Find the owner’s active broadcast (`liveBroadcasts.list?mine=true`). | unset |

Need either an API key plus a live chat or video id, or the OAuth refresh trio. Polling uses the API’s `pollingIntervalMillis`. X’s API needs a paid tier, and LinkedIn comments need a partner API; those destinations are not ingested.

## Twitch and Kick chat

While live, these comments join the same chat panel. Unset hides them.

| Name | Purpose | Local default |
|---|---|---|
| `TWITCH_CHANNEL` | Twitch channel name to read. | unset |
| `KICK_CHATROOM_ID` | Kick numeric chatroom id to read. | unset |

X chat is not supported yet because X has no free chat API.

## Stream keys

Stream keys are not environment variables. They live in Durable Object storage, never in the repo. The public API only returns a masked suffix such as `rtmp://…/xxxx`, plus a `hasKey` flag.

## Hosted mode (optional)

Hooks for a separate control plane that runs Casthop for many teams. Each one is off unless its variable is set. With none set, nothing changes.

| Name | Purpose |
|---|---|
| `CASTHOP_EXTERNAL_AUTH_KEYS` | Comma list of `kid:secret` (secret 32+ characters). Enables `GET /api/auth/external`. Otherwise it returns 404. |
| `CASTHOP_EXTERNAL_AUTH_ISSUER` | Required with the keys. The token `iss` must equal it. Unset means 404. |
| `CASTHOP_SIGNIN` | `external` turns off magic-link and GitHub sign-in (403 `signin_external`). Existing sessions and guest join keep working. `/api/config` returns `signin: "external"`. |
| `CASTHOP_SERVICE_KEYS` | Comma list of `kid:secret` (secret 32+ characters). Enables `/api/service/*`. Otherwise every route there returns 404. |

### Sign-in handoff

`GET /api/auth/external?token=<jwt>&next=<path>` signs the user in and redirects to `next`. `next` must start with a single `/` (no `//`, no backslash). Anything else goes to `/`.

The token is a compact JWS, HS256, with header `{"alg":"HS256","typ":"JWT","kid":"<kid>"}`.

| Claim | Rule |
|---|---|
| `iss` | Equals `CASTHOP_EXTERNAL_AUTH_ISSUER`. |
| `aud` | `casthop`. |
| `sub` | External user id, a string. |
| `email` | Valid email. The account is found or created by it, and pending invites are applied. |
| `exp` | Unix seconds, in the future and at most 120 s from now. |
| `iat` | Unix seconds. |
| `jti` | String, 128 characters or fewer. One use only. |
| `name` | Optional. |
| `tenant` | Optional. If present it must be a valid tenant id. |

### Service API

Every request to `/api/service/*` carries these headers:

| Header | Value |
|---|---|
| `X-Casthop-Key-Id` | The `kid`. |
| `X-Casthop-Timestamp` | Unix seconds. Must be within 300 s of the Worker clock. |
| `X-Casthop-Nonce` | 16 to 64 characters of `A-Za-z0-9_-`. Used once. |
| `X-Casthop-Signature` | Lowercase hex HMAC-SHA256. |

The signature is the HMAC-SHA256 of this string, keyed with the secret:

```text
${timestamp}\n${nonce}\n${METHOD}\n${pathname+search}\n${sha256hex(body)}
```

`body` is the raw request body, or the empty string when there is none. A bad signature, stale timestamp, unknown key or reused nonce returns 401 `{"error":"bad_signature"}`.

| Route | Does |
|---|---|
| `POST /api/service/studios` | Body `{tenantId, ownerEmail, ownerName?, name?}`. Creates a studio for the tenant. Returns 201 `{studio:{id,name,tenantId,ownerId}}`. |
| `GET /api/service/tenants/:tenantId/studios` | Returns `{studios:[{id,name,ownerId,createdAt}]}`. |
| `DELETE /api/service/studios/:id?tenantId=…` | Ends live output, deletes the studio's state, rows and files. 404 if it is not in that tenant. Returns `{deleted:true}`. |
| `DELETE /api/service/tenants/:tenantId` | Does the same for every studio of the tenant, then removes everything under `t/<tenantId>/`. Returns `{deleted:n}`. |

Accounts are never deleted by these routes.

A tenant id matches `^[a-z0-9][a-z0-9_-]{0,62}$`. Files of a studio with a tenant id are stored under `t/<tenantId>/` in the recordings bucket. Studios without one keep their keys.
