Gäste kommen über einen Link. Sie brauchen weder ein Konto noch eine Installation.

## So kommt ein Gast ins Studio

1. Der Host öffnet ein Studio und klickt auf **Invite guest**, um den Link zu kopieren.
2. Der Gast öffnet den Link, gibt einen Namen ein und prüft Kamera und Mikrofon.
3. Der Gast wartet hinter der Bühne. Der Host sieht ihn, aber er ist nicht im Stream.
4. Der Host holt ihn auf die Bühne. Bis zu sechs Leute können gleichzeitig auf der Bühne sein.

*Das grüne Bild stammt von einer simulierten Kamera in einer Testaufnahme, nicht von einem echten Gast.*

## Co-Hosts

Ein Co-Host kann das Studio gemeinsam mit dem Eigentümer leiten: Gäste auf die Bühne holen, das Layout ändern, live gehen und Chat anpinnen.

1. Der Eigentümer klickt auf **Invite co-host** und gibt eine E-Mail-Adresse ein.
2. Die Person bekommt eine E-Mail mit dem Studiolink. Der Eigentümer sieht dieselbe Antwort, egal ob es zu der Adresse ein Konto gibt.
3. Die Person meldet sich mit dieser E-Mail-Adresse an, öffnet den Link und klickt auf **Accept and join as co-host**. Bis sie zugestimmt hat, ist sie kein Co-Host.

Ein Co-Host kann ein Studio jederzeit verlassen.

## Wer darf was

- **Hosten braucht ein Konto.** Der Eigentümer und Co-Hosts melden sich per E-Mail-Link an, oder mit GitHub, wenn es eingerichtet ist.
- **Gäste können nicht als Host auftreten.** Der Server entscheidet, wer wer ist, und prüft jede Aktion.
- **Gäste sehen nie Stream-Keys.** Sie sehen nur die letzten paar Zeichen jeder Adresse. Siehe [Ziele](/docs/destinations).
- **Nur Leute auf der Bühne können ihre eigene Spur aufnehmen.** Ist **Separate recordings** an, nehmen Host, Co-Hosts und Gäste auf der Bühne jeweils in ihrem Browser auf. Gäste, die hinter der Bühne warten, können das nicht.

## Gäste-Limits

Damit niemand ein Studio mit falschen Gästen füllt, kann jedes Netz (eine IPv4-Adresse oder ein IPv6-/64-Block) bis zu 10 neue Gäste pro Minute hinzufügen und bis zu 16 Gästeplätze in einem Studio belegen. Ist ein Studio voll, verlieren Gäste, die länger als eine Minute weg sind, ihren Platz.

Denk daran, wenn viele echte Gäste im selben Büronetz sitzen.

## Wenn ein Gast nicht verbinden kann

TURN ist noch nicht dabei. TURN ist ein Relay-Server für Netze, die direktes Video blockieren. Ein Gast in einem strengen Büro- oder Hotelnetz kann scheitern. Bitte ihn, ein anderes Netz zu probieren, oder betreib mit LiveKit einen eigenen TURN-Server.
